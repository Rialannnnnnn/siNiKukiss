# SiNiKukiss

Website penjualan cookies. Murni HTML, CSS, dan JavaScript (tanpa framework, tanpa build).

## Isi folder
- index.html : struktur halaman
- style.css  : tampilan
- script.js  : produk, keranjang, animasi, pesan WhatsApp
- images/    : foto cookies

## Ubah data
Di script.js:
- WA_NUMBER : nomor WhatsApp (format 62...), sekarang 6285815787878
- HARGA     : harga per kukis, sekarang 20000
- PRODUCTS  : nama, deskripsi, dan foto tiap varian

## Upload ke GitHub dan tayang gratis (GitHub Pages)
1. Buat repository baru di GitHub, misalnya sinikukiss.
2. Upload semua isi folder ini (bukan zip-nya) ke repository.
3. Buka Settings > Pages. Pada Source pilih "Deploy from a branch", branch main, folder /(root), lalu Save.
4. Tunggu 1 sampai 2 menit. Alamat web muncul di halaman yang sama.
